Технические проблемы

Что-то реально сломано - зависло, не открылось, выдаёт ошибку.

  • Убедись, что скачана актуальная версия - code.claude.com/docs/en/desktop, не сторонние источники
  • На Windows иногда требуется обновление PowerShell - если появляется ошибка, попроси сам Claude Code подсказать команду обновления

В десктоп-версии иногда перетаскивание zip-архива в окно чата не срабатывает и выдаёт ошибку в духе "принимаются только картинки" - это известный баг интерфейса, не твоя ошибка.

РешениеНе перетаскивай архив в чат - вручную положи zip-файл в рабочую папку курса через проводник, и уже после этого попроси Claude Code: "поставь скилл из этой папки", указав путь. После установки перезапусти сессию (закрой и открой заново) - иначе новая команда не появится.
  • Чаще всего проблема с VPN - попробуй другой VPN или временно отключи
  • Проверь интернет-соединение
  • Копии папки хватает большинству. Но если правишь файлы каждый день - есть системный вариант: git, а хранилище - GitHub. По сути машина времени для папки: каждое сохранение создаёт точку, в которую можно вернуться
  • Команды учить не нужно. Заведи бесплатный аккаунт на github.com, дальше скажи Claude Code своими словами: "настрой git в этой папке и подключи мой GitHub, репозиторий сделай приватным". Потом - "сохрани текущее состояние с подписью, конец встречи 1"
  • Обязательно проговори "приватный", иначе рабочие файлы окажутся в открытом доступе
  • Если с регистрацией не сложилось - скажи "настрой git локально". Точки возврата будут работать, просто без копии в облаке

Типичные смысловые ошибки

Технически всё работает, но настроено не так, как нужно - и не всегда сразу заметно.

"Работаю в компании, помогай мне" вместо конкретики.

СимптомАссистент даёт универсальные советы, будто говорит с кем угодно, а не именно с тобой - не подстраивается под твою роль и тон.
Почему плохоЧем расплывчатее "Правила", тем более общие ответы получает модель - тот же принцип, что и с запросом: расплывчатый вопрос, расплывчатый ответ.
РешениеОткрой файл-инструкцию текстом и перепиши конкретнее: какая именно роль, какие задачи, какой тон предпочитаешь, что для тебя неприемлемо. Или заново пройди онбординг, отвечая максимально развёрнуто.
СимптомАссистент видит и пытается использовать лишние файлы, путается, предлагает нерелевантное.
Почему плохоОтдельная чистая папка нужна не только ради порядка, а чтобы у ассистента не было доступа к тому, что не относится к курсу.
РешениеСоздай новую чистую папку, попроси Claude Code работать только в ней, при необходимости перенеси туда уже созданные файлы-инструкции вручную.
СимптомКажется, что онбординг прошёл успешно, но на самом деле файл-инструкция не подгружается, и ассистент "не помнит" в новой сессии.
Почему плохоЕдинственный способ убедиться, что "память" реально работает - явно спросить в новой сессии; это работает только если проверку не пропустили.
РешениеОбязательно сделай контрольный вопрос ("как меня зовут" / "какая у меня роль") в свежей сессии - не в той, где шёл онбординг.
