Словарь терминов

Все новые слова курса в одном месте, по встречам - если забыл, что значит термин со встречи 2, не нужно пересматривать видео заново.

Встреча 1 · Настройка Claude и онбординг

Claude Code

Программа AI-помощник, которую ставишь на компьютер.

Скилл

Готовый промпт, который можно отправить файлом Claude и получить готовую инструкцию для регулярных действий.

Файл-инструкция ("Правила")

Анкета, которая рассказывает помощнику, кто ты и как с тобой общаться.

Daily-log

Ежедневный короткий опрос от Claude о твоём дне, 5 минут.

Встреча 2 · База знаний компании

Zettelkasten

Метод хранения знаний маленькими карточками-заметками со ссылками друг на друга, а не одним большим документом.

Атомарная заметка

Одна заметка = одна идея, короткая, своими словами.

Vault (хранилище)

Папка со всеми заметками, которую можно открыть в Obsidian и увидеть граф связей.

Связь

Ссылка между двумя заметками с объяснением, почему они связаны.

Встреча 3 · Автоматизация календаря, почты, Telegram

MCP

Переходник, который даёт помощнику доступ к другим программам - Telegram, почте, календарю.

API ID и API Hash

Бесплатные коды для регистрации "приложения" в Telegram, получаешь на my.telegram.org. Сами по себе доступа к переписке не дают.

Session string

Код, который выдаётся после входа по номеру телефона. Фактически открытая сессия в Telegram - куда более чувствительная вещь.

Триаж

Сортировка входящих сообщений и писем по важности.

Schedule Task

Задача, которая запускается сама по расписанию.

Мост WhatsApp

Небольшая программа на твоём компьютере, через которую ассистент читает WhatsApp. Ставится скиллом whatsapp-mcp-setup, вход по QR.

Unipile

Сервис-посредник, через который на встрече 4 ассистент получает доступ к LinkedIn.

Claude in Chrome

Расширение для Google Chrome, через которое Claude сам работает на сайтах.

Встреча 4 · ИИ-исследователь

Субагент

Отдельный ассистент-помощник, которого главный ассистент отправляет разобраться с одной задачей и вернуться с готовым результатом.

/council

Команда экспертов-субагентов, каждый даёт независимую оценку одного и того же вопроса.

Источниковедение

Умение понимать, какому источнику и в какой мере можно доверять.

Встреча 5 · Цифровая команда

Hook (хук)

"Рефлекс" ассистента, который срабатывает гарантированно в нужный момент, в отличие от инструкции, которую можно забыть.

Cron / Schedule Task

Расписание, по которому что-то запускается само.

Автономность

Насколько ассистент действует сам, без твоего запроса каждый раз.

Роль / Отчёт / Канал / Рабочий день

Четыре части модели найма любого цифрового сотрудника.
