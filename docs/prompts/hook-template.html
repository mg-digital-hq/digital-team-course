Шаблон: файл хука

Хук - это гарантия, что действие произойдёт автоматически, а не просто написано в инструкции и может быть забыто. Настраивается в файле settings.json.

  1. 1Самый простой способ - попроси Claude обычным языком: "настрой хук, который в начале каждой сессии напоминает мои главные приоритеты на неделю"
  2. 2Claude сам отредактирует .claude/settings.json - можешь свериться с шаблоном ниже, чтобы понимать, что он туда добавляет
  3. 3Перезапусти сессию Claude Code - конфигурация подхватывается не всегда мгновенно

Частые события для хуков

СобытиеКогда срабатывает
SessionStartВ начале каждой новой сессии - хорошо для напоминаний о приоритетах, роли, целях
PreCompactПеред сжатием длинного контекста - можно зафиксировать важные детали, пока их не потеряли
StopПеред завершением работы - например, не дать закончить, пока не пройдены проверки

Пример: напоминание приоритетов недели

.claude/settings.json
{
  "hooks": {
    "SessionStart": [
      {
        "hooks": [
          {
            "type": "command",
            "command": "cat ~/.claude/priorities-this-week.md 2>/dev/null || echo 'Файл приоритетов недели не найден - создай priorities-this-week.md'"
          }
        ]
      }
    ]
  }
}

Проверка: закрой и заново открой сессию Claude Code в рабочей папке - в начале должен появиться текст из priorities-this-week.md (или сообщение, что файл не найден). Если ничего не произошло - перепроверь, что событие в settings.json указано точно как SessionStart.
