Промпт 
Create a skill called atomize that:

1. Asks what I want to atomize (accepts text, a file path, or a pasted paragraph)
2. Reads the content
3. Extracts atomic ideas - each one gets its own note:
   - 1 concept per note
   - 2-5 sentences rewritten in MY words (not copy-paste from source)
   - Tags based on content
4. For each idea, searches my atomic/ folder for existing notes with potential connections
5. Creates files in atomic/ with format: YYYY-MM-DD_NNN.md using this template:

---
id: YYYY-MM-DD_NNN
title: "[Descriptive title]"
date: YYYY-MM-DD
source: "[source of the content]"
tags: []
---

# [Title]

[2-5 sentences expressing ONE idea in your own words.]

## Connections

- [[related-note-id]] - [Why this connects]

## Source Context

[Brief context about where this came from]

---
*Created via /atomize*

6. Uses [[wikilinks]] to connect related notes, with a brief explanation of each connection
7. Prints a summary: "X notes created, Y connections found to existing notes"

Put it in .claude/skills/atomize/SKILL.md

The skill should use these allowed-tools: AskUserQuestion, Write, Read, Bash, Glob, Grep

После вставки Claude Code создаст файл .claude/skills/atomize/SKILL.md, и скилл появится в списке команд как /atomize.
