# Онбординг - скилл встречи 1

Скилл для Claude Code, который проводит короткое интервью и создаёт первый слой курса "Цифровая команда компании" - файл-инструкцию.

## Что делает

10-15-минутное интервью, по итогам - до трёх файлов в рабочей папке:

| Файл | Назначение |
|---|---|
| `CLAUDE.md` | Файл-инструкция ("Правила") - Claude читает его в начале каждой сессии в этой папке |
| `goals.md` | Твои цели от системы |
| `SOUL.md` | Личность ассистента - только если задал характер на последнем вопросе |

## Установка

1. Создай отдельную чистую папку под курс.
2. Положи `SKILL.md` из этой папки в `<рабочая-папка>/.claude/skills/onboarding/SKILL.md`.
3. В Claude Code, открытом в этой рабочей папке, набери `/onboarding`.

## Проверка

После интервью открой новую сессию Claude Code в той же папке и спроси "как меня зовут" или "какая у меня роль". Если ответ верный - файл-инструкция подгружается, всё сработало.

## Для встречи 1

Соответствует Блоку 4 сценария встречи 1 ("Настройка Claude и онбординг"). QR-код на слайде HANDS-ON должен вести на публичную ссылку с этим `SKILL.md` (например, raw-ссылка на файл в репозитории курса) - без хостинга скилл не установить одной командой.
