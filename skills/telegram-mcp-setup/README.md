# telegram-mcp-setup - скилл встречи 3

Мастер подключения личного Telegram-аккаунта к Claude Code через MCP. Домашка встречи 3 курса "Цифровая команда компании" - без этого не заработает ни один из HANDS-ON шагов встречи, связанных с Telegram.

## Установка

1. Положи `SKILL.md` из этой папки в `<рабочая-папка>/.claude/skills/telegram-mcp-setup/SKILL.md`.
2. В Claude Code напиши "подключи Telegram" или "запусти telegram-mcp-setup" - скилл проведёт по всем шагам.

## Проверка

После подключения ассистент должен уметь прочитать реальные сообщения из Telegram по запросу вроде "покажи мои последние 3 сообщения".

## Примечание для адаптации

В основе - открытый пакет `telegram-mcp` (github.com/chigwell/telegram-mcp, лицензия Apache-2.0), устанавливается через `pip install telegram-mcp`, без Docker. Проверено на Windows - именно так подключён Telegram-MCP на рабочей машине курса.
