# cos-review - скилл встречи 5

Автоматическая версия чек-листа самодиагностики (встреча 5, Блок 2 / встреча 6, Блок 1). Сканирует файлы, MCP-подключения и настройки и сам считает баллы по 5 уровням (25 баллов) - вместо того чтобы отмечать галочки вручную на слайде.

## Установка

1. Положи `SKILL.md` из этой папки в `<рабочая-папка>/.claude/skills/cos-review/SKILL.md`.
2. В Claude Code напиши "запусти cos-review" или "проверь мою самодиагностику".

## Режимы

- **status** - только посчитать и показать баллы (по умолчанию)
- **setup** - посчитать баллы и предложить помощь по 1-2 самым простым пробелам
- **review** - посчитать баллы и сравнить с прошлым результатом (сохраняет историю в `notes/cos-review-history.md`)

## Проверка

После запуска должен появиться разбор по 5 уровням (L1-L5), суммарный балл из 25 и ранг (Стажёр → Правая рука) - без ручного заполнения слайда.
