# council - скилл встречи 4

Совет экспертов: 4-5 независимых экспертов-субагентов оценивают твоё решение и показывают, где согласны и где спорят. Встреча 4 курса "Цифровая команда компании", блок /council.

## Установка

1. Распакуй архив - получится папка `council` с файлом `SKILL.md`.
2. Положи папку в `~/.claude/skills/` (Windows: `C:\Users\Имя\.claude\skills\`, Mac: `/Users/Имя/.claude/skills/`).
3. Открой новую сессию Claude Code - в списке после `/` появится команда `/council`.

## Как пользоваться

```
/council Решение: <что решаем>. Оцените: стоит ли, какие риски, что я упускаю.
```

Лучше всего работает после ресерча в той же сессии: эксперты получают его как вводные.

## Что получишь

- Состав панели (кто и что оценивает, обязательно есть скептик)
- Независимые вердикты: ЗА / ПРОТИВ / ЗА, ЕСЛИ...
- Где эксперты согласны и где спорят
- Слепые пятна и вопросы, на которые ответить можешь только ты

Решение всегда остаётся за тобой.
