# /council - совет экспертов

Задача: дать пользователю независимую критическую проверку его решения. Не одно мнение, а несколько экспертов с разными интересами, которые не видят ответов друг друга. Ценность совета - в разногласиях: они вскрывают слепые пятна.

## Шаг 1. Пойми решение

- Решение берётся из текста после команды `/council`. Если его нет - спроси одним вопросом: «Какое решение оцениваем?»
- Если в текущем разговоре уже есть контекст (ресерч, документ, цифры) - используй его как вводные для экспертов.
- Сформулируй решение в одну фразу и покажи пользователю: «Оцениваем: ...».

## Шаг 2. Собери панель

Подбери 4-5 экспертов под это конкретное решение. Правила подбора:
- у каждого свой интерес и своя зона ответственности (деньги, клиент, право и риски, операционка, рынок и конкуренты, команда - что подходит к теме);
- обязательно один **скептик** - его задача найти, почему решение не сработает;
- эксперты не должны дублировать друг друга.

Покажи панель списком перед запуском: роль - что он оценивает (одна строка на эксперта).

## Шаг 3. Запусти экспертов параллельно

Запусти каждого эксперта отдельным субагентом (инструмент Agent / Task), **все одновременно, в одном сообщении**. Каждый субагент получает только:
- формулировку решения и вводные из разговора;
- свою роль и угол зрения;
- формат ответа ниже.

Ответы других экспертов субагент не видит - оценка должна быть независимой.

Формат ответа каждого эксперта:
```
Вердикт: ЗА / ПРОТИВ / ЗА, ЕСЛИ... (одно из трёх)
Главные аргументы: 2-3 пункта
Главный риск: одна фраза
Что упускает автор решения: одна фраза
Уверенность: высокая / средняя / низкая
```

Если субагенты недоступны - отыграй экспертов по очереди сам, но каждого отдельно и не оглядываясь на предыдущих.

## Шаг 4. Сведи итог

Покажи пользователю:

1. **Таблица вердиктов:** эксперт - вердикт - главный риск.
2. **Где согласны:** что подтвердили несколько экспертов.
3. **Где спорят:** явно назови разногласие - кто «за», кто «против» и почему. Не сглаживай спор, это самая ценная часть.
4. **Слепые пятна:** что упустил автор решения по мнению панели.
5. **Вопросы к тебе:** 2-3 вопроса, на которые может ответить только человек (данные, приоритеты, готовность рисковать).

Последней строкой: «Решение за тобой. Согласен ли ты с составом панели - кого не хватило?»

## Правила

- Не принимай решение за пользователя и не выдавай итог за единственно верный ответ.
- Факты, которых нет в вводных, помечай как предположение.
- Пиши кратко, без воды. В текстах не используй длинное тире, только обычный дефис " - ".
