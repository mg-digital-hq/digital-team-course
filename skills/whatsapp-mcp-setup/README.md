# whatsapp-mcp-setup - скилл встречи 3

Мастер подключения личного WhatsApp к Claude Code через MCP. Встреча 3 курса "Цифровая команда компании", блок 5.

## Установка

1. Положи `SKILL.md` из этой папки в `<рабочая-папка>/.claude/skills/whatsapp-mcp-setup/SKILL.md`.
2. В Claude Code напиши "подключи WhatsApp" или "запусти whatsapp-mcp-setup" - скилл проведёт по всем шагам: поставит нужные программы, запустит мост WhatsApp, попросит отсканировать QR телефоном и зарегистрирует MCP-сервер.

## Проверка

Попроси ассистента "покажи мои последние чаты в WhatsApp". Если список появился - подключение готово.

## Важно

- Мост WhatsApp - программа на компьютере, она должна быть запущена, пока пользуешься WhatsApp в Claude.
- Способ неофициальный (как WhatsApp Web). Для первого теста лучше второй номер.
- Отправка сообщений - только с подтверждением, сначала черновик.

## Примечание для адаптации

В основе - открытый проект `whatsapp-mcp` (github.com/lharries/whatsapp-mcp, лицензия MIT). Скилл переводит установку на русский, добавляет путь для Windows и команду регистрации в Claude Code.
