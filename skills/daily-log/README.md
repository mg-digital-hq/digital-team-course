# Daily-log - скилл встречи 1

5-минутный ежедневный журнал энергии, фокуса и настроения для Claude Code. Домашка встречи 1 курса "Цифровая команда компании" - данные, на которых через несколько встреч строятся более сложные вещи (паттерны, база знаний).

## Установка

1. Положи `SKILL.md` из этой папки в `<рабочая-папка>/.claude/skills/daily-log/SKILL.md`.
2. В Claude Code набери `/daily-log`.

## Проверка

В папке `notes/` появляется новый файл `daily-log-ГГГГ-ММ-ДД.md` после каждого запуска. Через 3 дня использования файлов должно быть три.

## Примечание для адаптации

Это переработанная версия открытого MIT-скилла daily-log под курс "Цифровая команда компании": интерфейс переведён на русский, убрана привязка к чужой учебной Telegram-группе, автоанализ паттернов ссылается на `goals.md` (создаётся скиллом онбординга встречи 1) вместо `user-profile.md`.
