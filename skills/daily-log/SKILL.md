# /daily-log - ежедневный журнал

Короткий чек-ин на 5 минут. Задай 6 вопросов, сохрани структурированную заметку. Не превращай это в долгий разговор - весь обмен должен укладываться в 5 минут.

## Перед вопросами - напоминание вчерашнего фокуса

1. Проверь папку `notes/` - есть ли файл `daily-log-ГГГГ-ММ-ДД.md` за последний предыдущий день (необязательно вчера календарно - просто самый свежий из существующих).
2. Если файл есть и в нём заполнен раздел `## Завтра` - покажи это одной строкой перед вопросом 1: "В прошлый раз ты решил, что сегодня важно: [текст из раздела Завтра]. Держим в фокусе?"
3. Если файлов ещё нет (самый первый запуск) - пропусти этот шаг, сразу начинай с вопроса 1.

Это текстовое напоминание в чате, показывается в момент запуска skill - не push-уведомление к конкретному часу. Настоящая доставка в заданное время по внешнему каналу (Telegram, почта) или через Schedule Task появится на встречах 3 и 5 - здесь этого сознательно нет.

## Ход интервью

Задавай вопросы по одному через `AskUserQuestion`. Тон - лёгкий, без формальностей.

### Вопрос 1. Энергия
- **Вопрос:** "Какая сегодня энергия?"
- **Варианты:** `["1-3 (низкая)", "4-5 (ниже среднего)", "6-7 (хорошая)", "8-10 (отличная)"]`
- Переведи ответ в число: низкая=2, ниже среднего=5, хорошая=7, отличная=9

### Вопрос 2. Фокус
- **Вопрос:** "Насколько хорошо получалось концентрироваться?"
- **Варианты:** `["1-3 (низкий)", "4-5 (ниже среднего)", "6-7 (хороший)", "8-10 (отличный)"]`
- Та же шкала перевода в число

### Вопрос 3. Настроение
- **Вопрос:** "Как в целом настроение?"
- **Варианты:** `["1-3 (низкое)", "4-5 (ниже среднего)", "6-7 (хорошее)", "8-10 (отличное)"]`
- Та же шкала перевода в число

### Вопрос 4. Главное за день
- **Вопрос:** "Что было главным событием дня?"
- **Варианты:** `["Сделал что-то важное", "Был хороший разговор", "Узнал что-то новое", "Свой вариант"]`
- Принимай любой свободный ответ - варианты только подсказка

### Вопрос 5. Что мешало
- **Вопрос:** "Что тормозило или раздражало?"
- **Варианты:** `["Слишком много встреч", "Не получалось сосредоточиться", "Застрял на задаче", "Ничего особенного", "Свой вариант"]`

### Вопрос 6. Завтра
- **Вопрос:** "Какая одна вещь важна на завтра?"
- **Варианты:** `["Закончить ключевую задачу", "Начать что-то новое", "Разобрать накопившееся", "Свой вариант"]`

### Вопрос 7. Во сколько напомнить
- **Вопрос:** "Во сколько тебе завтра напомнить про этот фокус?"
- Свободный ответ (например, "9:00" или "с утра"). Сохрани как есть, без строгого формата.
- Уточни честно, если человек не спросил сам: "Это не push-уведомление - я просто покажу это, когда ты в следующий раз откроешь Claude Code или запустишь /daily-log, ближе к этому времени."

## Сохранение записи

1. Получи сегодняшнюю дату в формате ГГГГ-ММ-ДД (`date +%Y-%m-%d` через Bash).
2. Создай папку `notes/` в рабочей папке, если её ещё нет.
3. Сохрани файл `notes/daily-log-ГГГГ-ММ-ДД.md`:

```markdown
# Дневной лог - ГГГГ-ММ-ДД

## Показатели
- Энергия: X/10
- Фокус: X/10
- Настроение: X/10

## Главное
[ответ]

## Что мешало
[ответ]

## Завтра
[ответ]

## Напомнить в
[ответ на вопрос 7]

---
*Записано через /daily-log*
```

## После сохранения

Выведи одну строку подтверждения:

> Записал. Энергия X, фокус X, настроение X. Напомню про фокус около [время] - когда в следующий раз откроешь Claude Code. До завтра.

## Автоанализ паттернов (каждая 3-я запись)

После сохранения посчитай все файлы `notes/daily-log-*.md`. Если их количество делится на 3 (3, 6, 9, 12...):

1. Прочитай все файлы дневных логов в `notes/`
2. Если рядом есть `goals.md` (создан скиллом онбординга на встрече 1) - прочитай и его для контекста
3. Проанализируй паттерны: тренды энергии/фокуса/настроения по дням, повторяющиеся помехи, корреляции, лучшие окна продуктивности
4. Добавь или обнови раздел `## Паттерны из дневных логов` в конце `goals.md` - 5-8 пунктов, кратко, заменяя предыдущую версию, а не дописывая поверх
5. Скажи: "Обновил goals.md паттернами из X записей."

Начиная со встречи 2, эти же записи становится удобно атомизировать скиллом `/atomize` в базу знаний - упомяни это, если человек уже прошёл встречу 2.

Не предлагай публикацию или отправку записи куда-либо - это личный журнал, дальше него запись не должна никуда уходить без явной просьбы человека.
